# Status

Open with the bottom line, then the facts that support it, then what is left.

1. **Bottom line.** One sentence: is it over, and what the reader has to do.
2. **Key facts.** Three to five numbers or claims the reader would repeat: how
   long, how many, how much. Each one cited.
3. **What is left.** Open `action` facts with an owner, and `decision` facts
   still waiting on someone. A `closed-by-decision` action is listed with its
   rationale, so it doesn't read as forgotten.
4. **Where the detail is.** A link to the analysis view.

Show certainty as a label only where it changes what the reader should do: a
claim still `inferred` reads as "likely" with what would confirm it.
