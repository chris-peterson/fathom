# kinds

The kinds fathom ships are examples any team can build on, so they stay
generic: name a source by its category (audit trail, metrics, application
logs), never by a vendor, tool, or team. Team-specific sources, commands, and
templates belong in a kind that extends one of these, kept outside this repo
(see `docs/extending.md`).

A fact type describes the work, not a document: `cause` is a fact type, a "root
cause section" is a brief's choice.
